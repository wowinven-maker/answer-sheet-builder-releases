# AnswerSheet Builder

Windows용 답안 입력 앱의 설치 파일을 배포하는 저장소입니다.

[최신 설치 파일 받기](https://github.com/wowinven-maker/answer-sheet-builder-releases/releases/latest)

`AnswerSheetBuilder-Setup-버전.exe`를 내려받아 설치하세요. 소스 코드는 따로 관리합니다.

1.25.0부터 앱이 하루 한 번 새 버전을 확인하고 내려받습니다. 도움말(F1)의 `이 프로그램`에서 `저장하고 업데이트`를 눌렀을 때 열린 답안지를 저장하고 설치합니다. 일반 종료 때는 설치하지 않습니다.

Windows x64용이며 코드 서명은 아직 적용하지 않았습니다. 설치 파일에 학생 자료는 들어 있지 않습니다. 함께 들어 있는 제출 양식에는 머리글만 있습니다.

업데이트 뒤 앱이 열리지 않으면 설치 파일을 다시 실행하세요. 받아 둔 설치 파일은 `%LOCALAPPDATA%\AnswerSheetBuilder\updates`에 있습니다.
